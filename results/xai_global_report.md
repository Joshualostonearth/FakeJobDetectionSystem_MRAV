Generated by `python scripts/xai_global_report.py` on the 3151-posting EMSCAD test split (seed 42). Runtime: 266 s on CPU (global attributions 128 s).

All attributions are exact for the M1 TF-IDF SVM: contribution = averaged LinearSVC weight x feature value, and contributions + intercept equal the averaged decision function. Positive = towards FAKE. Word scores include the char n-grams that fall inside each word. Means are over all test postings (a word absent from a posting contributes 0 to it).
